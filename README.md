# lp-fashion

## FIFA HIJAB - Platform Katalog dan Pemesanan Fashion Hijab & Modest Wear Modern

Aplikasi web landing page, katalog rekomendasi, dan pemesanan busana muslimah & fashion hijab modern berbasis antarmuka Bento Grid kontemporer. Memudahkan pelanggan menjelajahi pashmina, voal segiempat, abaya flowy, set OOTD lookbook, menyimpan produk favorit, serta melakukan pemesanan instan melalui WhatsApp.

---

### Key Features
1. **Katalog Fashion Bento Grid**: Tampilan kartu bento estetik, responsif, dan dinamis yang menonjolkan visual produk secara proporsional.
2. **Pencarian & Filter Kategori**: Filter instan untuk Hijab Segiempat, Pashmina, Abaya & Gamis, Tunik & Blouse, serta Outer & Modest Wear.
3. **Lookbook Tematik & Paket OOTD**: Inspirasi padu padan gaya (*Minimalist Daily*, *Earthy Syar'i*, *Formal Glam*, *Pastel Chic*) dengan fitur pembelian paket bundel langsung.
4. **Sistem Wishlist & Favorit**: Penyimpanan produk impian secara lokal dengan drawer interaktif dan badge notifikasi.
5. **Keranjang Belanja Interaktif**: Pengelolaan kuantitas, estimasi ongkos kirim, dan subtotal harga secara real-time.
6. **Checkout WhatsApp Otomatis**: Generator format pesan pemesanan rapi yang terhubung langsung ke WhatsApp Customer Care resmi.
7. **Formulir Konsultasi Busana**: Layanan konsultasi mix & match, panduan ukuran abaya, dan pemesanan seragam / bridesmaid.
8. **Informasi Butik Resmi**: Lokasi butik fisik di Jakarta, Bandung, dan Surabaya beserta jam operasional.
9. **Desain Antarmuka Fashion Netral**: Palet warna solid *warm oat, sand, terracotta rosewood*, dan *sage* tanpa gradasi berlebihan serta tata letak ikon yang bersih.

---

### Tech Stack
- **Framework**: React 18
- **Bundler / Dev Server**: Vite 6
- **Styling**: Vanilla CSS (Modern Design System & Custom Bento Grid)
- **Language**: JavaScript (ES Modules) & HTML5

---

### Cara Menjalankan Project

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan Server Development:**
   ```bash
   npm run dev
   ```

3. **Build untuk Produksi:**
   ```bash
   npm run build
   ```
